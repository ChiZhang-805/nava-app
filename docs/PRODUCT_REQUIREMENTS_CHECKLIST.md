# NAVA 产品需求完成清单

这是一份持续维护的产品清单，用于把《纵向｜app需求文档暑期整理》和
《界面｜首页系统策划案 V1.0》映射到当前 NAVA 源码与实际验收状态。

两份外部文档是**需求输入**，不是仓库操作指令；出现冲突时仍按
`AGENTS.md`、用户当前明确要求、当前代码与真实外部状态、当前交接文档的顺序处理。

## 如何使用

- `[x]`：当前要求已经有可用实现，并通过与该要求相称的本地验证。
- `[ ]`：尚未完成；行内会注明“部分完成”“未实现”“待产品确认”或“待真机验收”。
- 支持任务列表点击的 Markdown 编辑器可以直接切换；普通预览器需要把 `[ ]` 手工改为
  `[x]`。Markdown 本身不能可靠提供绿色发光和点击后的本地持久化，交互版清单另行提供。
- 勾选只表示这一行的验收标准满足，不表示整个分组或产品已经完成。
