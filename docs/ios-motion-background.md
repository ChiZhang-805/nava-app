# iOS 动态背景、角色动画与原生媒体

## Figma 衣橱布局与二维动画候选（2026-10-25）

衣橱商品页现在按 Figma 移动端 C04/C05 的空间关系使用 2×2 卡片，每页固定最多 4 件；
分页逻辑和 3D 预加载同样按 4 件处理。预览区加入不接收触摸的虚线圆角框，并按三套 APP
皮肤分别使用冰蓝、紫蓝青和蓝绿色调。现有单饰品替换、3D/2D 切换、兑换及积分合同不变。

对静态正面小猫制作二维动画时，生产路线优先考虑 Live2D Cubism 或 Rive：它们通过网格、
骨骼和状态机驱动原图，更适合保持脸、毛发与配饰形状。DomoAI 与 Runway 可用静态图快速生成
动作视频或用参考视频迁移动作，但输出会重新生成像素，需要逐帧检查角色漂移、额外肢体、配饰
位移和透明边缘。当前只完成官方能力与费用调研，未登录外部服务、购买额度或把生成视频接入 APP。

- Live2D Cubism：提供 42 天 PRO 试用，之后可使用受限 FREE 版；适合把分层 PSD 绑定成保形动画，
  可导出视频、GIF 或透明视频。每套配饰需要单独准备遮挡关系与变形网格。
- Rive：适合把网格、骨骼和状态机直接带入 APP；免费层可导出带 Rive 启动画面的 `.riv`，
  去除启动画面并用于无品牌生产发布时需 Cadet 或更高计划。
- DomoAI：适合把一张静态图快速生成 5–10 秒 MP4；实际生成需要登录并消耗额度，付费计划移除水印。
- Runway：Image-to-Video、Motion Control 或 Act-Two 可用参考动作驱动角色；使用网页或 API 都需要
  账号，API 需购买 credits。适合作为动作草样，不能承诺逐像素保持原角色。

### 商城二维动画最终格式决定（2026-10-25）

商城生产资产统一选择 Rive `.riv`，用位图网格、骨骼和状态机制作原地待机与点击挥爪；React
运行时直接播放 `.riv`，不把图生视频结果当成商城主资产。这样可以保持小猫原始脸、毛发、尾巴、
配饰和透明背景，并让点击、循环、暂停和减少动态效果由 APP 控制。Rive Cloud Renderer 导出的
GIF/WebM 只用于人工审核；若运行时加载失败，再使用同动作的 animated WebP 降级。GIF 不作为
生产首选，因为颜色、透明边缘和体积不适合这套柔和渐变毛发。

第一阶段只做无配饰基础小猫：`idle` 静止/轻呼吸、`wave` 右前爪轻挥两次并精确回到初始姿势，
状态机由点按触发且不移动身体、头、左爪和尾巴。该原型通过后，共用同一套骨架和动作曲线扩展
到 17 个单配饰版本；每款仅处理配饰遮挡、绑定和必要的局部跟随。Rive Editor 登录页面已准备，
等待用户本人登录后创建云端工程；尚未创建账号、购买计划或上传素材。

## 行为

- 未移动手机时，背景继续按原有节奏自动流动。
- 手机轻微倾斜时，背景沿对应方向产生额外位移、波纹和光影变化。
- 姿态带来的额外速度最高为原动画速度的 50%，停止移动后平滑回落。
- 传感器不可用、用户拒绝授权或开启“减少动态效果”时，仅保留原有背景动画。
- 动作数据只在当前页面的内存中参与渲染，不上传、不写入本地存储。

## iOS 权限

首次进入引导页时不弹权限框；用户点击“开始体验”后，应用才请求动作与方向权限。用途文案为：

> NAVA 使用设备动作数据，让动态背景轻微响应您的手机移动。数据仅在设备本地用于视觉效果。

在 Mac 上执行以下任一命令，会自动向 `ios/App/App/Info.plist` 写入
`NSMotionUsageDescription`：

```bash
npm run cap:add:ios
npm run cap:sync
```

也可以单独执行：

```bash
npm run ios:configure-motion
```

## 真机验收

1. 使用 HTTPS 或 Capacitor iOS 应用打开 NAVA。
2. 点击“开始体验”，允许动作与方向访问。
3. 保持手机静止，确认原动画持续运行。
4. 分别向左、右、上、下轻微倾斜，确认纹理和光影沿相同方向响应。
5. 快速移动后停止，确认增强在约一秒内平滑衰减，不发生跳变。
6. 拒绝权限并重新进入，确认登录和原背景动画不受影响。
7. 开启 iOS“减少动态效果”，确认姿态联动停用。

## 录音、播放和相机中断（当前实现及验收边界）

网页桌面右侧系统事件可随时触发，只有当前可见且运行中的活动接收中断。录音中断会取消监听及
待授权请求，保留已识别文字；朗读中断清队列并拒绝迟到流片段；相机中断停止所拥有的
视频轨道。回到页面不会自动开麦、开镜头或提交记录。按钮明确是模拟，不真实拨号。

`NavaSpeechPlugin` 监听 AVAudioSession interruption、旧音频路由断开和进入后台。
请求代次隔离迟到权限及识别回调，只在前台启动；取消不依赖前端监听清理成功。
Windows 上的源码合同与外部 Chromium 模拟不等于 iPhone 录音、锁屏及常亮验收。
仍须 Mac/Xcode 编译并用真实 iPhone 测试拒绝/迟到授权、来电、耳机拔出、锁屏/解锁、
手动恢复及麦克风指示灯，填写真机记录后才能关闭设备门槛。

系统事件依据：[Apple 音频中断说明](https://developer.apple.com/documentation/AVFAudio/handling-audio-interruptions)。
